At Vue Fes Japan 2026, we're launching a new initiative to support future engineers by offering a special assistance program for students. This program not only helps reduce financial burden, but also provides valuable opportunities to connect with the Vue.js community.

Note: The student support program is intended for residents of Japan only.

### Requirements

- Students (university, graduate school, vocational school, high school, etc.)
- Interest in Vue.js or frontend development
- Availability to attend the event in October 2026

For more details, please see the application guidelines.
